# SA_Time

《心灵终结》3.3.6 的独立对局计时插件。透明计时框横向居中，距战场顶部约为框宽的 1.3 倍，满一小时从 `MM:SS` 切换为 `HH:MM:SS`。

从开局按逻辑帧计时。单机 5 速和联机 6 速均为每 60 帧计 1 秒。暂停或等待同步时停表，换速只影响之后的计时。读档后按存档帧号和恢复的速度换算。

## 安装

将 `dist` 中的 `SA_Time.dll` 和 `SA_Time.ini` 放入 `gamemd.exe` 所在目录，下次开局生效。计时默认开启，在 `[MatchClock]` 中设置 `Enable=0` 可关闭。使用带内置计时的 SapphireA 旧版时，请关闭其计时功能，或升级至 1.0.741-selected.7 及以上。

## 编译

使用 32 位 MinGW-w64 运行 `python build.py`。可通过 `MOE_MINGW` 指定工具链的 `bin` 目录。
